## Как использовать

### Через пользовательский интерфейс:
1. Откройте главную страницу приложения
2. Найдите счетчик результатов (например, "Найдено: 5" или "Всего карточек: 42")
3. Нажмите на кнопку "+" (плюс) рядом со счетчиком
4. Откроется модальное окно **точно такое же как при редактировании карточки**, с:
   - Выпадающими списками колоды и темы (вверху, 2 колонки)
   - Панелью форматирования текста
   - Пустыми полями вопроса и ответа (contenteditable divs)
5. Выберите колоду и тему из выпадающих списков
6. Заполните вопрос и ответ (оба поля обязательны)
7. При необходимости примените форматирование текста
8. Нажмите "Создать" или используйте `Ctrl+Enter` для сохранения
9. Нажмите "Отмена" или `Escape` для отмены

**Порядок блоков в модальном окне:**
1. Колода | Тема (в 2 колонки)
2. Панель форматирования
3. Вопрос
4. Ответ
5. [Отмена] [Создать] (кнопки внизу справа)

### Через API:
```javascript
POST /api/card/create?username={username}
Content-Type: application/json

{
  "question": "Текст вопроса",
  "answer": "Текст ответа",
  "category": "Колода (необязательно, по умолчанию: 'Без колоды')",
  "subcategory": "Тема (необязательно, по умолчанию: 'Общее')",
  "formatting": {
    "question": [],
    "answer": []
  }
}
```

**Ответ:**
```json
{
  "ok": true,
  "card": {
    "question": "Текст вопроса",
    "answer": "Текст ответа",
    "formatting": {...}
  },
  "totalCards": 43
}
```

## Технические детали

### Выпадающие списки колод и тем

Модальное окно создания включает два связанных выпадающих списка:
- **Колода** - заполняется динамически из всех доступных колод в системе
- **Тема** - автоматически обновляется при изменении колоды

Связь между списками работает следующим образом:
1. При открытии модального окна загружаются все колоды из `buildCategoriesFromData(getRuntimeData())`
2. При выборе колоды список тем обновляется соответствующими темами
3. Если у колоды нет тем, используется значение по умолчанию "Общее"

### Поток данных:
1. Пользователь нажимает кнопку "+" → вызывается `openCreateModal()`
2. Открывается модальное окно с пустыми `contenteditable` редакторами И выпадающими списками колод/тем
3. Пользователь выбирает колоду и тему из выпадающих списков (динамически связанных)
4. Пользователь заполняет вопрос и ответ и нажимает "Создать"
5. `saveCreateChanges()` извлекает текст, форматирование, колоду и тему из модального окна
6. Отправляется POST запрос на `/api/card/create` с колодой и темой
7. Сервер создает новую карточку с указанными колодой и темой
8. Карточка сохраняется в файл `data/user_{username}.json`
9. localStorage обновляется новой карточкой
10. Генерируется событие `qaDataUpdated` для обновления UI
11. Показывается уведомление об успехе

### Структура данных карточки:
```javascript
{
  category: "Выбранная колода",
  subcategory: "Выбранная тема",
  question: "Текст вопроса",
  answer: "Текст ответа",
  formatting: {
    question: [{ start, end, color, bold, italic, underline, code }],
    answer: [...]
  }
}
```

### Горячие клавиши в модальном окне:
- `Ctrl+Enter` - Создать карточку
- `Escape` - Отменить создание

### Валидация:
- Вопрос не может быть пустым
- Ответ не может быть пустым
- Пользователь должен быть авторизован
