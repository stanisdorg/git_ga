# Редактирование карточек в режиме обучения

## Описание функциональности

Добавлена возможность редактирования карточек (вопроса и ответа) прямо во время сессии обучения. Изменения сохраняются на сервере и применяются для текущего пользователя.

## Измененные файлы

### 1. `server.js`
Добавлен новый API эндпоинт:
- **URL:** `POST /api/card/update`
- **Параметры:**
  - `username` (query) - имя пользователя
  - `oldQuestion` (body) - исходный текст вопроса (для поиска карточки)
  - `newQuestion` (body) - новый текст вопроса
  - `newAnswer` (body) - новый текст ответа
- **Ответ:**
  - `{ ok: true, message: 'card_updated' }` - успех
  - `{ ok: false, error: '...' }` - ошибка

**Особенности:**
- Автоматическое исправление поврежденных UTF-8 символов
- Логирование всех операций (logger.info, logger.error)
- Проверка наличия карточки по старому вопросу
- Сохранение в персональный файл пользователя `data/user_{username}.json`

### 2. `srs/learn-ui.js`
Добавлена функциональность редактирования:

**Импорты:**
- Добавлен импорт `syncWithServer` из `storage.js`

**UI элементы:**
- Кнопка редактирования (карандаш) на front и back карточки
- Модальное окно редактирования с двумя полями (вопрос и ответ)
- Уведомления об успехе/ошибке сохранения

**Функции:**
- `openEditModal(card)` - открытие модального окна редактирования
- `closeEditModal(discardChanges)` - закрытие модального окна
- `saveEditChanges()` - сохранение изменений на сервере
- `showEditNotification(message, type)` - показ уведомления

**Состояние:**
- `editModalState` - объект состояния модального окна

**Логирование:**
- Все этапы логируются через `console.log` с префиксами:
  - `[EDIT]` - действия с кнопкой редактирования
  - `[EDIT MODAL]` - операции модального окна
  - `[EDIT NOTIFICATION]` - показ уведомлений

### 3. `custom-styles.css`

## Как использовать

1. Запустите сессию обучения
2. На карточке (спереди или сзади) нажмите на иконку карандаша слева
3. Откроется модальное окно с полями вопроса и ответа
4. Отредактируйте текст (поддерживается выделение, вставка, удаление)
5. Нажмите "Сохранить" или `Ctrl+Enter` для сохранения
6. Нажмите "Отмена" или `Escape` для отмены изменений
7. После сохранения появится уведомление "Изменения сохранены"
8. Карточка в сессии обновится с новыми данными

## Горячие клавиши

- `Ctrl+Enter` - сохранить изменения
- `Escape` - закрыть модальное окно (отмена)

## Обработка ошибок

**На клиенте:**
- Проверка на пустые поля (вопрос и ответ обязательны)
- Проверка авторизации пользователя
- Перехват ошибок сети и сервера
- Показ уведомления с текстом ошибки

**На сервере:**
- Проверка наличия `username`
- Валидация JSON
- Проверка наличия карточки по `oldQuestion`
- Обработка ошибок записи файла

## Синхронизация

После успешного сохранения изменений вызывается `syncWithServer()` для синхронизации всех данных пользователя с сервером.

## Хранение данных

Изменения сохраняются в:
- Файл сервера: `data/user_{username}.json` (структура: `userData._cards[]`)
- Персональные данные каждого пользователя независимы

## Тестирование

**Проверка функциональности:**
1. Авторизуйтесь под пользователем
2. Запустите режим обучения
3. Нажмите на иконку карандаша
4. Измените текст вопроса/ответа
5. Нажмите "Сохранить"
6. Проверьте уведомление "Изменения сохранены"
7. Проверьте, что карточка обновилась в сессии
8. Проверьте файл `data/user_{username}.json` на сервере

**Проверка ошибок:**
1. Попробуйте сохранить пустой вопрос - должно появиться уведомление об ошибке
2. Отключите сервер и попробуйте сохранить - должно появиться уведомление об ошибке сети
3. Нажмите "Отмена" - изменения не должны сохраниться
