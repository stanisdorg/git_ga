# ✅ Исправление проблемы: Черный экран при переходе на статистику

## 🎯 Проблема
При переходе на статистику из тренировки (модалки с результатами) пользователь видел черный экран.

## 🔍 Причины (ДВЕ проблемы)

### Проблема 1: Hashchange обработчик не создавал stats-container
Hashchange обработчик предполагал что `initStatsPage()` уже был вызван, но это неверно для перехода из тренировки.

### Проблема 2: Если hash уже #/stats, hashchange не срабатывает
Если страница открыта с `#/stats`, то присваивание `location.hash = '#/stats'` **не вызывает** событие hashchange!

## ✅ Что исправлено

### 1. srs/learn-ui.js (строки 921-943) - ФИНАЛЬНОЕ ИСПРАВЛЕНИЕ
- Вызов `initStatsPage()` напрямую из кнопки "Статистика"
- Не полагаемся на hashchange событие
- Обработка ошибок импорта

### 2. ui-variants/tabs-navigation.js (строки 647-673)
- Проверка существования stats-container
- Вызов initStatsPage() если контейнер не найден
- Добавлено скрытие sidebar

### 3. srs/stats-ui.js (hideStatsPage)
- Очищается ссылка `statsContainer = null` после удаления
- Явно устанавливается `mainContainer.style.display = 'block'`

### 4. srs/stats-ui.js (initStatsPage)
- Добавлена проверка через getComputedStyle() для отладки

## 🧪 Как проверить

### Быстрый тест:
1. Откройте http://localhost:8085
2. Пройдите 2-3 вопроса в тренировке
3. В модалке нажмите кнопку "Статистика"
4. **Должна открыться страница статистики с графиками**

Ищите логи:
```

[STATS INIT] stats-container created
[STATS INIT] stats-container display set to block
[STATS INIT] Hid sidebar
```
