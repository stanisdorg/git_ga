# Инструкции для AI-ассистента

## 1. Git и Коммиты
- **Язык**: Все сообщения коммитов (git commit messages) должны быть СТРОГО на РУССКОМ языке.
- **Автоматизация**: После выполнения задачи всегда выполнять `git add .`, `git commit -m "..."` и `git push`.
- **Подтверждение**: Не требовать подтверждения для git-операций, если они следуют из логики задачи.

## 2. Версионность
- **Отображение**: Версия приложения должна отображаться в шапке сайта (мелкий шрифт, ненавязчиво).
- **Обновление**: С каждым изменением кода необходимо инкрементировать номер версии.
- **Формат**: Использовать числовой формат (например, v22, v23) или семантический (v1.0.22).
- **Местоположение**: Версия должна быть определена в коде так, чтобы её легко было найти и обновить.

## 3. UI/UX Предпочтения
- **Стиль кнопок**: Использовать класс `.nav-icon-btn` для кнопок навигации (минимализм).
- **Расположение**: Кнопки управления (Домой, Вход/Выход, Статистика) должны быть слева (`flex-start`).
- **Текст**: Избегать дублирования заголовков (например, "Статистика").

## 4. Общие требования
- **Инициатива**: Если видишь ошибку или возможность улучшения (в рамках задачи), предлагай или исправляй.
- **Контекст**: Всегда проверяй текущую структуру проекта перед созданием новых файлов.
