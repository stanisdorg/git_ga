# Trae PWA

Прогрессивное веб-приложение (PWA) с возможностью офлайн-доступа на мобильных устройствах.

## Особенности

- Полноценная работа в офлайн-режиме
- Возможность установки на домашний экран мобильного устройства
- Адаптивный дизайн для различных устройств
- Кэширование ресурсов для быстрой загрузки

## Установка

1. Клонируйте репозиторий
2. Откройте приложение в браузере
3. Для установки на мобильное устройство используйте опцию "Добавить на главный экран" в меню браузера

## Деплой

Проект настроен для автоматического деплоя через Netlify при пуше в GitHub репозиторий.
