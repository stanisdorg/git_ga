Популярные карточки

Что такое замыкание в JavaScript?
Замыкание — это функция, которая запоминает свое лексическое окружение, даже если она выполняется вне этого окружения.
JavaScript Функции
Объясните разницу между var, let и const
var имеет функциональную область видимости, let и const — блочную. const не позволяет переassign, но может изменять свойства объектов.
JavaScript Переменные
Что такое Event Loop?
Event Loop — это механизм, который позволяет JavaScript выполнять асинхронные операции, перемещая задачи из очереди задач в стек вызовов.
JavaScript Асинхронность
Что такое промисы?
Promise — это объект, представляющий результат успешного или неудачного завершения асинхронной операции. Имеет три состояния: pending, fulfilled, rejected.
JavaScript Асинхронность
Что такое CSS Grid?
CSS Grid Layout — это двухмерная система компоновки, которая работает со строками и столбцами одновременно, упрощая создание сложных макетов.
CSS Layout
Что такое Flexbox?
Flexbox — это модель макета CSS, которая позволяет элементам адаптироваться к размеру контейнера и распределять пространство между элементами.
CSS Layout
Что такое React Hooks?
Hooks — это функции, которые позволяют использовать состояние и другие возможности React в функциональных компонентах. Основные: useState, useEffect, useContext.
React Hooks
Что такое SQL инъекция?
SQL-инъекция — это атака, при которой злоумышленник может выполнить произвольный SQL-код, вставляя его в запросы приложения.
Базы данных Безопасность
Что такое нормализация БД?
Процесс организации данных в базе данных для уменьшения избыточности и улучшения целостности данных. Включает несколько нормальных форм (1NF, 2NF, 3NF и т.д.).
Базы данных Проектирование
Что такое async/await?
async/await — это синтаксический сахар над промисами. async объявляет асинхронную функцию, await приостанавливает выполнение до разрешения промиса.
JavaScript Асинхронность
Что такое виртуальный DOM?
Виртуальный DOM — это легковесная копия реального DOM. React использует его для оптимизации обновлений, сравнивая изменения и применяя только необходимые.
React Архитектура
Что такое Python декоратор?
Декоратор — это функция, которая принимает другую функцию и расширяет её поведение, не изменяя её код. Использует синтаксис @decorator_name.
