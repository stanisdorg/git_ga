# 🔴 Критическая проблема: Кодировка UTF-8

## Проблема

**ВСЕ файлы проекта** (79 файлов) содержат битую кодировку UTF-8.

Символы кириллицы были заменены на символы замены (, U+FFFD) при сохранении файлов в неправильной кодировке.

## Поражённые файлы

### JavaScript файлы (39 файлов)
- `admin-panel.js`
- `all-data.js`
- `auto-logger.js`
- `server.js`
- `ui-manager.js`
- `srs/*.js` (algorithm.js, learn-ui.js, stats-ui.js, storage.js, etc.)
- `ui-variants/*.js` (tabs-navigation.js, sidebar-navigation.js, etc.)
- `tests/*.js`
- И другие...

### JSON файлы данных (22 файла)
- `data/global.json` (316 карточек с битыми ответами)
- `data/user_*.json` (все файлы пользователей)
- `data/final_questions.json`
- `data/backup/*.json`
- И другие...

### HTML файлы
- `index.html`
- `logs.html`
- `manifest.json`

## Причина

Файлы были сохранены в кодировке **CP1251 (Windows-1251)** вместо **UTF-8**, и символы кириллицы были безвозвратно потеряны.

## Примеры искажений

```
Оригинал: "Документация"
Искажено: "Дкументация" или "Дкументация"

Оригинал: "непрерывная интеграция"
Искажено: "непрерывная интеграция"
```

## Решение

### Вариант 1: Найти оригинальные файлы ⭐ (Рекомендуется)
- Найти резервную копию с правильной кодировкой
- Скачать исходный репозиторий
- Скопировать файлы с другого компьютера

### Вариант 2: Перекодировать файлы
```bash
# Попытка перекодировки (может не помочь, символы уже потеряны)
iconv -f CP1251 -t UTF-8 input.js > output.js
```

### Вариант 3: Переписать файлы вручную
- Самый надёжный, но самый трудоёмкий способ
- Требует доступа к оригинальному контенту
