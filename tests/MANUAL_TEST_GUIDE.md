# Ручное тестирование исправления проблемы с обновлением UI

## Проблема
После редактирования карточки в режиме обучения изменения не видны на главной странице до перезагрузки.

## Сценарий ручного тестирования

### Шаг 1: Подготовка
1. Запустите сервер: `node server.js`
2. Откройте браузер: `http://localhost:8765`
3. Залогиньтесь под тестовым пользователем (если требуется)

### Шаг 2: Переход в режим обучения
1. Нажмите кнопку "Статистика" (иконка графика)
2. На странице статистики нажмите "Продолжить обучение" или "Обучение"
3. Должна открыться страница с карточками для обучения

### Шаг 3: Редактирование карточки
1. Найдите карточку для редактирования (например, "Медленный деплой")
2. Нажмите кнопку редактирования (иконка карандаша) на карточке
3. Откроется модальное окно редактора

### Шаг 4: Внесение изменений
1. Измените текст вопроса (добавьте "[TEST]" в конец)
2. Измените текст ответа
3. Примените форматирование (например, выделите цветом)
4. Нажмите "Сохранить"

**Ожидаемое поведение в консоли браузера (F12):**
```
[EDIT MODAL] ✅ localStorage обновлён
[EDIT MODAL] ✅ Событие qaDataUpdated отправлено
```

### Шаг 5: Выход из режима обучения
1. Нажмите кнопку "Выход" вверху страницы
2. Вы попадёте на страницу статистики

### Шаг 6: Переход на главную страницу
1. Нажмите кнопку "Домой" или перейдите по хэшу `#/`
2. **КЛЮЧЕВОЙ МОМЕНТ**: Проверьте, видна ли изменённая карточка

**Ожидаемое поведение в консоли браузера (F12):**
```
[qaDataUpdated] 🔥 Получено событие об изменении карточки
[qaDataUpdated] 🔄 Вызываем refreshCurrentContext()
[refreshCurrentContext] 🔥 START
[refreshCurrentContext] Runtime data count: 317
[refreshCurrentContext] Calling showAllQuestions
[refreshCurrentContext] ✅ displayQuestions completed
[refreshCurrentContext] 🔥 END
```

### Шаг 7: Проверка результата

**✅ УСПЕХ**: Изменённая карточка видна сразу (например, "Медленный деплой [TEST]")

**❌ ПРОВАЛ**: Карточка со старым названием, изменения видны только после перезагрузки страницы

## Отладка

Если тест не проходит:

### 1. Проверьте localStorage
Откройте консоль браузера (F12) и выполните:
```javascript
const cards = JSON.parse(localStorage.getItem('qaUserCards'));
console.log('Карточек:', cards.length);
console.log('Последние карточки:', cards.slice(-3).map(c => c.question));
```

Должна быть карточка с изменённым вопросом.

### 2. Проверьте события
В консоли должно быть событие `qaDataUpdated`:
```javascript
window.addEventListener('qaDataUpdated', (e) => {
    console.log('Событие получено!', e.detail);
});
```

### 3. Проверьте обработчик
Убедитесь, что обработчик зарегистрирован:
```javascript
console.log('Обработчик:', window.refreshCurrentContext);
// Должно быть: [Function: refreshCurrentContext]
```

### 4. Принудительное обновление
Попробуйте вызвать обновление вручную:
```javascript
window.refreshCurrentContext();
```

## Автоматические тесты

Для запуска автоматических тестов:

```bash
# Запуск сервера (в отдельном окне)
node server.js

# Запуск тестов Playwright
npx playwright test tests/card-edit-flow.test.js --headed
```

## Логи для отладки

Ищите в консоли следующие метки:
- `[EDIT MODAL]` - логирование редактирования
- `[qaDataUpdated]` - логирование события
- `[refreshCurrentContext]` - логирование обновления UI

## Критерии приёмки

- ✅ Изменения видны сразу после перехода на главную
- ✅ Перезагрузка страницы не требуется
- ✅ В консоли нет ошибок
- ✅ Событие `qaDataUpdated` диспатчится и обрабатывается
- ✅ `refreshCurrentContext()` вызывается автоматически
