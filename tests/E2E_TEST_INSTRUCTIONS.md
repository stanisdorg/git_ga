# Инструкция по запуску E2E тестов

## Тест полного цикла редактирования карточки

### Файл: `tests/card-edit-full-flow.test.js`

Этот тест проверяет **весь путь** от авторизации до проверки изменений в избранном:

1. ✅ Авторизация
2. ✅ Проверка начального состояния localStorage
3. ✅ Переход в режим обучения
4. ✅ Редактирование карточки (текст + цвет)
5. ✅ Сохранение
6. ✅ Проверка localStorage после сохранения
7. ✅ Выход из режима обучения
8. ✅ Переход на главную страницу
9. ✅ Проверка что изменения видны
10. ✅ Переход в избранное
11. ✅ Проверка карточки в избранном

### Как запустить

#### Шаг 1: Авторизуйтесь в приложении

1. Откройте браузер и перейдите на http://localhost:8085
2. Войдите под пользователем `admin` (или другим)
3. Дождитесь загрузки карточек

#### Шаг 2: Запустите тест

```bash
npx playwright test tests/card-edit-full-flow.test.js --headed
```

Флаг `--headed` откроет браузер чтобы вы видели что происходит.

#### Шаг 3: Смотрите логи

В консоли вы увидите детальный лог каждого шага:

```
[E2E] ШАГ 0: Проверка авторизации
[E2E] ✅ Пользователь авторизован: admin
[E2E] ШАГ 1: Загрузка главной страницы
[E2E] ✅ Главная страница загружена
[E2E] ШАГ 2: Проверка начального состояния
[E2E] Начальное состояние: { qaUserCardsCount: 316, ... }
...
[E2E] ✅ ТЕСТ УСПЕШНО ЗАВЕРШЁН
```

### Что проверяет тест

#### Критические проверки (тест упадёт если не пройдут):

1. **refreshCurrentContext существует** - функция обновления UI
2. **setUniqueQaData существует** - функция обновления данных
3. **Карточка сохранена в qaUserCards** - основной ключ
4. **Карточка сохранена в qaUserCards_admin** - ключ пользователя
5. **Флаг qaCardsUpdated установлен** - для отложенного обновления

#### Мягкие проверки (просто логируются):

1. Карточка видна на главной странице
2. Карточка видна в избранном
3. Форматирование сохранено

### Если тест падает

#### 1. "Пользователь не авторизован"

**Решение:** Войдите в приложение перед запуском теста

#### 2. "qaUserCards пуст"

**Решение:** Дождитесь загрузки данных с сервера (5-10 секунд после загрузки страницы)

#### 3. "Карточка не найдена в избранном"

**Возможные причины:**
- Карточка не была добавлена в избранное
- `qaFavorites` не обновился
- `getRuntimeData()` не возвращает изменённую карточку

**Как отладить:**
Смотрите логи `[showFavorites]` - они покажут:
- Сколько карточек в избранном
- Сколько найдено в runtimeData
- Какие вопросы найдены
