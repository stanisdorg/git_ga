# Автотесты: Переход на статистику из тренировки

## Проблема
При переходе на страницу статистики из режима обучения (тренировки) пользователь видит черный экран.

## Найденные и исправленные проблемы

### 1. Не очищалась ссылка на удаленный stats-container
**Файл:** `srs/stats-ui.js`, функция `hideStatsPage()`

**Проблема:** После удаления stats-container из DOM, переменная `statsContainer` продолжала ссылаться на удаленный элемент.

**Решение:** Добавлено `statsContainer = null` после удаления элемента.

### 2. Неявное отображение mainContainer
**Файл:** `srs/stats-ui.js`, функция `hideStatsPage()`

**Проблема:** `mainContainer.style.display = ''` оставлял пустое значение, что могло приводить к невидимости.

**Решение:** Явно установлено `mainContainer.style.display = 'block'`.

### 3. Отсутствие проверки вычисленных стилей
**Файл:** `srs/stats-ui.js`, функция `initStatsPage()`

**Проблема:** Не было проверки что stats-container действительно видим после создания.

**Решение:** Добавлена проверка через `window.getComputedStyle()` для отладки.

1. Откройте приложение в браузере (http://localhost:8085)

## Возможные проблемы

### Черный экран
Причины:
1. `stats-container` не создан или не видим
2. `sidebar` перекрывает статистику (z-index)
3. `mainContainer` не был скрыт

### Ошибки в логах
```
[STATS INIT] stats-container exists: false
[STATS INIT] main container display: 
```
Пустой `display` означает, что контейнер не был явно скрыт.

## Решение проблемы

См. файл `stats-ui.js`, функция `initStatsPage()`:
- Убедиться, что `.sidebar` скрывается принудительно
- Убедиться, что `.container` скрывается до создания stats-container
- Проверить z-index для stats-container
