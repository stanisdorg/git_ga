# ВАЖНЫЕ ИНСТРУКЦИИ ДЛЯ AI (CRITICAL RULES)

## 🚨 ГЛАВНОЕ ПРАВИЛО: ЗАКОНЧИЛ РАБОТУ -> ОТПРАВЬ В GIT
**Ты обязан автоматически выполнять `git commit` и `git push` после каждого завершенного логического блока изменений.**
- **НЕ СПРАШИВАЙ** разрешения.
- **НЕ ЗАБЫВАЙ** об этом.
- Если ты написал "Я исправил ошибку", но не сделал push — ты НЕ выполнил задачу.

## 🔄 ПОРЯДОК ДЕЙСТВИЙ (CHECKLIST)
Перед тем как сказать пользователю "Готово":
1.  **Проверь код**: Убедись, что изменения корректны.
2.  **Обнови версию**:
    - Увеличь `APP_VERSION` в `ui-manager.js`.
    - Обнови импорты (например, `?v=26` -> `?v=27`) во всех зависимых файлах (`ui-manager.js`, `stats-ui.js`, `tabs-navigation.js`).
3.  **Сохрани**: `git add .`
4.  **Закоммить**: `git commit -m "Описание на РУССКОМ"`
5.  **Отправь**: `git push`
6.  **Только потом отвечай пользователю.**

## 1. Git и Коммиты
- **Язык**: Все сообщения коммитов (git commit messages) должны быть СТРОГО на РУССКОМ языке.
- **Автоматизация**: `git push` обязателен.

## 2. Версионность
- **Отображение**: Версия приложения должна отображаться в шапке сайта.
- **Обновление**: С каждым изменением кода необходимо инкрементировать номер версии в `ui-manager.js` и параметрах импорта.

## 3. UI/UX Предпочтения
- **Стиль кнопок**: Использовать класс `.nav-icon-btn`.
- **Расположение**: Кнопки управления слева.

## 4. Общие требования
- **Инициатива**: Если видишь ошибку, исправляй.
- **Backup**: Перед рискованными операциями делай бэкап (`npm run backup`).
