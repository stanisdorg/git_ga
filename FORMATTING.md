# Форматирование текста в карточках

## Возможности

Теперь в режиме редактирования карточек доступно форматирование текста:

### Цвета текста
- 🟠 `#F5B042` — оранжевый
- 🔶 `#FF8C42` — тёмно-оранжевый
- 🟦 `#4ECDC4` — бирюза
- 🟣 `#B794F4` — фиолетовый
- 🩷 `#FF9F7C` — коралловый
- 🟩 `#7FCDCD` — мята
- 🔴 `#FF6B6B` — красный

### Цвета фона
Те же 7 цветов с прозрачностью 20% для лучшей читаемости.

### Форматирование
- **Жирный** (Ctrl+B)
- *Курсив* (Ctrl/I)
- <u>Подчёркивание</u> (Ctrl+U)
- `Код` (Ctrl+E) — моноширинный шрифт + фон

## Как использовать

1. Откройте карточку в режиме обучения
2. Нажмите на кнопку редактирования (карандаш)
3. Выделите текст в редакторе
4. Нажмите на кнопку цвета или форматирования
5. Сохраните изменения (Ctrl+Enter или кнопка "Сохранить")

## Технические детали

### Структура данных
Форматирование хранится в отдельном поле `formatting`:

```json
{
  "question": "Что такое DOM?",
  "answer": "Document Object Model",
  "formatting": {
    "question": [
      {
        "start": 12,
        "end": 15,
        "color": "#FF6B6B",
        "bold": true
      }
    ],
    "answer": [
      {
        "start": 0,
        "end": 8,
        "backgroundColor": "rgba(78, 205, 196, 0.2)"
      }
    ]
  }
}
```

### Файлы
- `srs/text-formatter.js` — ядро форматирования (конвертация, применение стилей)
- `srs/format-toolbar.js` — UI компонент toolbar
- `style.css` — стили toolbar
- `custom-styles.css` — стили отображения в карточках
- `srs/learn-ui.js` — интеграция в редактор
- `server.js` — серверная поддержка (сохранение formatting)

### Горячие клавиши
- `Ctrl+B` — жирный
- `Ctrl+I` — курсив
- `Ctrl+U` — подчёркивание
- `Ctrl+E` — код
- `Ctrl+Enter` — сохранить изменения

## Мобильная версия

На смартфонах toolbar адаптируется:
- Кнопки становятся крупнее (40×40px для удобного тапа)
- Цвета скроллятся горизонтально если не помещаются
- Подписи скрыты для экономии места

## Архитектура

Выбран вариант с **отдельным полем `formatting`** (JSON) вместо HTML в тексте:

**Преимущества:**
- Чистые данные (текст отдельно, стили отдельно)
- Легко экспортировать/импортировать
- Проще парсить для других целей
- Можно изменить отображение без изменения данных

**Недостатки:**
- Сложнее реализация (нужен слой конвертации)
- Нужно синхронизировать при редактировании текста

## Будущие улучшения
