🖥️ Клиентские приложения

  • PWA — index.html + script.js + sw.js
  • Electron — main.js + preload.js + stt_worker.py
  • Mobile — iOS Safari / Android Chrome (PWA режим)
  • UI навигация — tabs, dropdown, sidebar варианты

🚀 Сервер (Node.js)

  • Auth Module — Login, OAuth, Rate Limiting
  • Cards Module — CRUD карточек
  • Data Module — Save/Load, Metadata, Trash
  • SRS Module — Алгоритм интервалов, планировщик
  • Admin Module — Логи, управление
  • Webhooks — Telegram Bot, iPhone logs

💾 Хранилище данных

  • users.json — База пользователей (SHA-256 пароли)
  • user_{name}.json — Данные пользователя
  • user_{name}_metadata.json — Метаданные
  • user_{name}_trash.json — Корзина
  • global.json — Глобальные карточки

☁️ Внешние сервисы

  • GitHub OAuth — Авторизация через GitHub
  • Google OAuth — Авторизация через Google
  • Telegram Bot API — Вход + проверка подписки
  • Sentry — Мониторинг ошибок
  • Cloudflare — DNS + CDN + Tunnel
