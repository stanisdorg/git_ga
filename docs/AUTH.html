🔐 Методы аутентификации

ByteCards поддерживает 4 способа входа в систему:

1. Username + Password

Классическая аутентификация по логину и паролю. Пароли хешируются SHA-256 с солью.

Rate Limiting: 5 попыток, блокировка на 15 минут.

POST /api/login
{ "username": "jeff", "password": "mypassword" }

2. GitHub OAuth

Авторизация через GitHub. Пользователь перенаправляется на GitHub, после успешной авторизации создаётся или находится существующий пользователь.

GET /api/auth/github → Redirect to GitHub
GET /api/auth/github/callback?code=XXX → Auth complete

3. Google OAuth

Авторизация через Google. Email используется как уникальный идентификатор.

POST /api/auth/google
{ "email": "user@gmail.com", "name": "User", "googleId": "..." }

4. Telegram Auth

Авторизация через Telegram с проверкой подписи данных и обязательной подпиской на канал @brotherhood_qa.

POST /api/auth/telegram
{ "id": 123456, "username": "user", "hash": "xxx", "auth_date": "..." }

👥 Роли пользователей

РольОписаниеПрава
editorОбычный пользовательСоздание/редактирование карточек
adminАдминистраторВсе права + просмотр логов + регистрация пользователей

📁 Хранение данных

Данные пользователей хранятся в data/users.json:

[
  {
    "username": "jeff",
    "password": "sha256_hash",
    "role": "editor",
    "email": "jeff@example.com",
    "githubId": "12345",
    "createdAt": "2026-01-01T00:00:00.000Z",
    "lastLoginAt": "2026-04-04T12:00:00.000Z"
  }
]

🔒 Безопасность

  • Пароли хешируются SHA-256 с солью
  • Rate limiting на login (5 попыток / 15 мин)
  • Telegram auth проверяет HMAC-SHA256 подпись
  • Проверка подписки на канал для Telegram
  • Валидация username (только буквы, цифры, _)
